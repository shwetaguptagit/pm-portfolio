# Shweta Gupta · Product Portfolio

Senior Product Manager, B2C growth and subscriptions.

Live site: https://shwetaguptagit.github.io/pm-portfolio/

A single static page (`index.html`) with images in `img/`. No build step.

Two views:
- **Portfolio** (default): funnel impact, case studies, shipped screens, earlier roles, AI work, FirstLight Careers.
- **Presentation**: a 10-slide deck for interviews. Open it at `#present`, move with ← →, press F for full screen.

Light and dark themes follow the system setting, with a toggle in the top bar. To preview locally:

```bash
python3 -m http.server 4173
```
